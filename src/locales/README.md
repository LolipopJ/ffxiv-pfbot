# Sources of localized text

English | [简体中文](./README-chs.md)

Game terminology should preferably use the client text for the corresponding language in the `ffxiv-data` submodule. Align translations by table name and row ID, rather than looking up English strings alone. For example, `Loot` has different translations in the loot interface and in Party Finder recruitment purposes.

| Content                                                     | Client table and row IDs                                               |
| ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| Duty Roulette, Dungeons, Guildhests, Trials, Raids          | `ContentType` 1, 2, 3, 4, 5                                            |
| PvP, FATEs, Treasure Hunt, Gold Saucer, Deep Dungeons       | `ContentType` 6, 8, 9, 19, 21                                          |
| V&C Dungeon Finder, The Hunt                                | `ContentType` 30, 33                                                   |
| High-end Duty                                               | `Addon` 10822                                                          |
| Gathering Forays, Field Operations, Other                   | `Addon` 2306, 2307, 10894                                              |
| Recruitment purposes: None, Duty Completion, Practice, Loot | `Addon` 10924–10927                                                    |
| Duty Complete, One Player per Job                           | `Addon` 10079, 11178                                                   |
| Recruiter, Comment, Time Limit, Average Item Level          | `Addon` 2208, 2209, 2214, 2216                                         |
| Job names and English abbreviations                         | `Name` and `Abbreviation` columns in `ClassJob`, aligned by job row ID |
| Any (no role restriction)                                   | Role option text in `Addon` 2300; abbreviated as `Any` in English      |

English job labels use the client abbreviations; other languages use the full client job names. The data source represents beastmaster as `BSM`, so keep the object key `BSM`, but display the beastmaster name or abbreviation `BST` from `ClassJob` 43. Do not use the blacksmith name from `ClassJob` 9. The current submodule has no Korean text for `ClassJob` 43, so it temporarily uses the English client abbreviation `BST`; replace it when official Korean text becomes available.

Display text may include necessary context, such as “Minimum item level.” Subscription, cleanup, permission, and error messages describe bot features and should use natural, consistent local wording. Preserve placeholder parameters, filter values, and Discord's length limits.

Internal log messages and module labels also belong to the bot's locale packs and follow `LANGUAGE`. Keep event identifiers, structured context keys, and interpolation parameters consistent across languages. UTC timestamps and external error details retain their original format or text.

Duty and treasure map dictionaries in `generated/*.ts` are generated by `scripts/build-dict.ts`. Update the client data and generation script rather than editing generated files directly. Keep the original text when a client translation is unavailable; do not invent official names.
