# 本地化文本来源

[English](./README.md) | 简体中文

游戏术语优先使用 `ffxiv-data` 子模块中对应语言的客户端文本。通过表名和行 ID 对齐翻译，不能仅按英文字符串查找：例如 `Loot` 在战利品界面和队员招募目的中对应不同译文。

| 内容                                             | 客户端表及行 ID                                           |
| ------------------------------------------------ | --------------------------------------------------------- |
| 随机任务、迷宫挑战、行会令、讨伐歼灭战、大型任务 | `ContentType` 1、2、3、4、5                               |
| 对战、危命任务、寻宝、金碟游乐场、深层迷宫       | `ContentType` 6、8、9、19、21                             |
| 特殊迷宫探索、怪物狩猎                           | `ContentType` 30、33                                      |
| 高难度任务                                       | `Addon` 10822                                             |
| 采集活动、特殊场景探索、其他                     | `Addon` 2306、2307、10894                                 |
| 招募目的：无、完成任务、练习、反复攻略           | `Addon` 10924–10927                                       |
| 任务已完成、职业不重复                           | `Addon` 10079、11178                                      |
| 招募人、留言、招募期限、平均品级                 | `Addon` 2208、2209、2214、2216                            |
| 职业名称及英文缩写                               | `ClassJob` 的 `Name`、`Abbreviation` 列，按职业行 ID 对齐 |
| 所有人（不限职能）                               | `Addon` 2300 的职能选项文本；英文简写为 `Any`             |

英文职业展示沿用客户端缩写，其他语言使用客户端职业全名。数据源以 `BSM` 表示驯兽师，因此保留对象键 `BSM`，展示值按 `ClassJob` 43 使用驯兽师名称或缩写 `BST`，不要取锻铁匠（`ClassJob` 9）的名称。当前子模块的韩文 `ClassJob` 43 为空，暂用英文客户端缩写 `BST`；获得官方韩文文本后再替换。

展示文本允许增加必要的上下文，例如“最低装等”。订阅、清理、权限和错误提示属于机器人功能，采用自然且一致的本地表达；同时保留占位参数、筛选值及 Discord 的长度限制。

内部日志信息和模块标签同样保存在机器人语言包中，跟随 `LANGUAGE`。各语言的事件标识、上下文字段键和占位参数须保持一致；UTC 时间戳和外部错误详情保留原格式或原文。

`generated/*.ts` 的任务与寻宝地图词典由 `scripts/build-dict.ts` 生成。应更新客户端数据和生成脚本，不直接手改生成文件。客户端暂缺的译名保留原文，不自行编造正式名称。
